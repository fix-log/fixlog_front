# 🛠️ Fixlog

Fixlog는 개발자들이 문제 해결 과정을 기록하고, 공유하며, 함께 성장하는 커뮤니티 플랫폼입니다.  
Next.js, TailwindCSS, FSD 구조를 기반으로 설계되었습니다.

## 🚀 프로젝트 소개

- **목표**: 개발자들이 겪은 오류 및 해결 방법, 노하우를 기록하고 공유하는 공간 제공
- **핵심 기능**
  - 커뮤니티 피드(전체/팔로잉)
  - 피드 작성 및 댓글
  - 문제/해결 기록, 검색
  - 사용자 팔로우 및 개인 피드
  - 프로젝트/모집 게시판 (확장 예정)
  - 반응형 웹 지원

---

## 📦 기술 스택

- **Framework**: [Next.js](https://nextjs.org/) (App Router)
- **Styling**: [TailwindCSS](https://tailwindcss.com/)
- **폴더 구조**: [FSD(Feature-Sliced Design)](https://feature-sliced.design/ko/)
- **상태관리**: Zustand, React Query (필요 시)
- **기타**: Axios, shadcn/ui, lucide-react 등
